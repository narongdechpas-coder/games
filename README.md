# Games

เกมบนเบราว์เซอร์ เปิด `index.html` เพื่อเข้าหน้าเลือกเกม

| โฟลเดอร์ | เกม | ไฟล์ออฟไลน์ |
|---|---|---|
| `battleship/` | Battleship 3D | `battleship-offline.html` |
| `thai-checkers/` | หมากฮอสไทย | `thai-checkers-offline.html` |
| `pok-deng/` | ป๊อกเด้ง วงเที่ยงคืน | `pok-deng-offline.html` |

`index.html` ในแต่ละโฟลเดอร์โหลด library และฟอนต์จาก CDN ส่วนไฟล์ `*-offline.html` รวมทุกอย่างไว้ในไฟล์เดียว เปิดได้โดยไม่ต้องต่อเน็ต
